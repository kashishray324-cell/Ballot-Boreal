# One-minute demo script

**0:00–0:08** — Open Ballot Boreal. “This is a member ballot designed to verify eligibility without making a voter record public.”

**0:08–0:18** — Point to the public requirement. “The cooperative publishes the eligibility rule and deadline. That is all the ballot needs to explain.”

**0:18–0:32** — Point to the privacy boundary. “The credential, signature, vote, and proving material stay in the wallet. Midnight receives only ‘eligible’ and an unlinkable one-time nullifier.”

**0:32–0:42** — Switch Preview/Preprod and show 1AM connection. “Changing networks deliberately resets the session. The app discovers the wallet through the Midnight connector and prefers 1AM.”

**0:42–0:54** — Start proof generation. “The proof is generated locally. The UI never invents a transaction—it waits for wallet submission and network finalization.”

**0:54–1:00** — Show the public metrics/receipt state. “Observers get an aggregate and a finalized receipt, not identities, credentials, or vote choices.”
